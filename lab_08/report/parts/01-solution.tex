\subsection{База знаний}
Исходный код базы знаний <<Собственники>> приведен в листинге~\ref{lst:t2-prog}.
\begin{listing}[Исходный код базы знаний <<Собственники>>]{lst:t2-prog}{Prolog}
total_price(Name, TotalPrice) :-  
    property_price(Name, auto, AutoPrice), !,
    property_price(Name, structure, StructPrice), !,
    property_price(Name, land, LandPrice), !,
    property_price(Name, vessel, VesselPrice), !,
    is(TotalPrice, +(+(AutoPrice, StructPrice), +(LandPrice, VesselPrice))).

property_price(Name, Kind, Cost) :- asset(Name, Kind, _, Cost, _).
property_price(_, _, 0).

\subsection{Вопросы задания}

Для получения названий всех объектов собственности заданного субъекта необходимо 
задать вопрос: существуют ли такие Вид\_собственности, Модель при конкретизированной 
Фамилии, для которых удовлетворяется отношение \code{asset}.

\begin{listing}[Вопрос 1]{lst:q1}{Prolog}
?- asset(Surname, Type, Model, \_, \_).
\end{listing}

Для получения названий и стоимости всех объектов собственности субъекта 
необходимо задать вопрос: существуют ли такие Вид\_собственности, 
Модель, Цена при конкретизированной Фамилии, для которых удовлетворяется отношение \code{asset}.

\begin{listing}[Вопрос 2]{lst:q2}{Prolog}
?- asset(Surname, Type, Model, Price, \_).
\end{listing}

Для получения суммарной стоимости всех объектов собственности заданного субъекта 
необходимо задать вопрос: существует ли Полная\_стоимость при конкретизированной 
Фамилии, для которых удовлетворяется отношение \code{total\_price}.

\begin{listing}[Вопрос 3]{lst:q3}{Prolog}
?- total\_price(Surname, TotalPrice).
\end{listing}
